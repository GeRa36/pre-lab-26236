# Sin TACC

## Propósito del sitio

Sin TACC es un sitio web creado como proyecto para el curso
Talento Tech Front End JS.

El objetivo del sitio es brindar información útil para personas
celíacas y facilitar la búsqueda de productos y opciones sin TACC.

## Contenido del sitio

El sitio contará con diferentes secciones:

- Inicio
- Productos
- Contacto

También se incorporarán imágenes, contenido multimedia,
reseñas y diferentes recursos para mejorar la experiencia
del usuario.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Formulario de contacto

El sitio cuenta con un formulario de contacto que permite
ingresar nombre, correo electrónico y mensaje.

El formulario utiliza Formspree para gestionar el envío
de los mensajes.
